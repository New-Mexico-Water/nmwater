## How to use this data

- **Rocky Arroyo flood events.** Peak storage and days impounding.

## Read before quoting a number

- This is a dry dam. It is empty by design, and percent full is measured against the flood pool, so small numbers are normal. Peak storage, `days_flood_storage` and `peak_flood_pct` carry the signal: each is a flood being held.
- Percent full is not meaningful for a dry dam.

## Capacity history

Reported storage departs from the current table in earlier years because older tables were in force. 1 table era was found, detected by comparing each year with the previous one over the elevations both occupied. Departure is the median of reported storage minus the current table's storage at the same elevation. Capacities are at today's pool elevations.
