# Navajo Lake

_Generated by `scripts/reservoir_fill.py` from `catalog/reservoirs.yaml`. Edit the registry, not this file._

Reclamation's Colorado River Storage Project reservoir on the San Juan, completed in 1963 and the second-largest reservoir in New Mexico. It supplies the Navajo Indian Irrigation Project and other San Juan basin uses, and its releases are shaped to meet flow recommendations for endangered fish in the San Juan River.

## How to use this data

- **San Juan basin supply.** Storage is the supply for the Navajo Indian Irrigation Project and municipal and industrial users in the Four Corners.
- **Endangered-fish flows.** Spring release peaks record the flows shaped for the San Juan River Basin Recovery Implementation Program.
- **Colorado River context.** Navajo is part of the upper Colorado system, so its condition reflects basin-wide drought as much as local runoff.

## Read before quoting a number

- The Corps' CWMS storage series for Navajo runs about 51,000 acre-feet off its own table, likely an elevation datum difference, and is not used. Reclamation's series reproduces the table exactly.
