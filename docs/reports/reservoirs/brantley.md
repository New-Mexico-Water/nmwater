## How to use this data

- **Carlsbad irrigation supply.** Percent of the conservation pool is the meaningful fill measure.
- **Lower Pecos floods.** Storage above the conservation pool is flood water; 2014 and 2015 show it clearly.

## Read before quoting a number

- This is a flood-control dam. Percent full is measured against the conservation pool, which is what the dam normally holds. Storage above it is flood water being held back, measured by `days_flood_storage` and `peak_flood_pct`. Dividing storage by the dam's total or design capacity answers a different question and will read very low.
- An earlier version of this report measured Brantley against its spillway, making it look far emptier than it is. It is now measured against its conservation pool.
- The conservation pool is redefined almost every year by an entitlement; the current value is used for every year.

## Capacity history

Reported storage departs from the current table in earlier years because older tables were in force. 5 table eras were found, detected by comparing each year with the previous one over the elevations both occupied. Departure is the median of reported storage minus the current table's storage at the same elevation. Capacities are at today's pool elevations, so where a published pool capacity history exists above it takes precedence for percentages.
